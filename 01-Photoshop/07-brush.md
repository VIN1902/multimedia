# Basic
- `B` for brush.
- right click for settings.
- `[ , ]` for size control.
- `alt + right click (hold)` then drag up/down for hardness and left/right for size.
- `shift` for straight line.
- `alt` for color sampler.
- you can create (background should be white then edit > define brush preset) and download (install .arb file and then import brush from setting icon of brushes) brushes too.
- from windows > brush settings you can change brush dynamics like size and angle jitter (randomness).

# Color Replacement
- contiguous = jha tak contnously color ja rha (beech me obstacle color nhi arha) then vahi tak replace karega.
- discontiguous = jo color select kiya vo brush ke radius mei vha sab jagha replace hoga, even if beech mei koi obstacle (diff color) bhi h to.
- tolerence = range of colors it considers while sampling
- foreground color se replace hoga
- continous sample, sample once, and background sample are options.
