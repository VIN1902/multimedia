# Crop tool
- crops the entire project/canvas space, not just the images/layers inside it.
- un-check 'delete cropped pixels' in order to have access of original pixels after cropping for adjustments. but still the whole panel will be cropped.
- use file > revert to go back.

# Straighten
- option within crop tool used for straightening tilted images.
- click a point and drap to draw a line to set that line as horizontal refrence.
- adjust the pixels and centre the subject of image with rule-of-third overlay after straightening.

# Content-aware fill
- option in crop tool that fills the trasparent pixels of solid or pattern background upon crop.
- can also be used to extend the image beyond its size.

# presective crop tool
- use this to straighten skewed images.
