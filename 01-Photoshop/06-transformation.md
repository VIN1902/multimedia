# Basic
- `ctrl + T`
- `shift` = stretch not scale
- `alt` = scale from centre

# Rotation
- `shift` for locking angle.
- from options select the anchor/reference point after ctrl + T.

# Flip
- after ctrl + T, right click and at the end flip vertical/horizontal.

# Skew
- ctrl + T then right click and skew
    - skewers the image at an angle.
- perspective shortens or lengthens any side.
- distort skewers free-form. (most used)
- warp is distort + curves.

# Rotate transform
- select object then `ctrl + alt + T` for making its copy and tranform that copy. move that copy vertically or horizontally.
- then `ctrl + alt + shift + T` for repeating the above operation automatically. spam it.
- `ctrl + E` to join multiple layers into one.
