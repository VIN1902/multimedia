# Basic
- tools like these work directly on pixels of layer. so we can make a new layer on top and toggle 'sample all layers' to work on new layer but get pixel data from the one below.
- `alt` to sample something first then start painting. the crosshair symbol shows where the circle is sampling from currently.
- keep brush hardness very low or none for clone tool to work like a charm.
- blending mode options let you select sample normally but only the darken or lighten part of sample will be cloned.
- align when checked moves the smapling crosshair from original position once you stop holding down lmb and starts sampling from new location.

# clone source panel
- can save multiple samples by alt clicking and saving them into top row.
- can control the size of clone by controlling width and height after sampling.
- can also flip from the same place vertically or horizontally. rotate too.
- uncheck clipped and then turn down opacity to see how it will look before painting.

# Heal tool
- clone one just makes a copy but heal tool tries to blend and match the sampled area to nearby area.
- spot healing: take brush size slight larger than spot and then click on it to match that spot with nearby texture and all. (auto-samples)
- healing brush: same as spot healing but need to specify samples.
- darken, multiply: no action to 'heal' is taken for dark spot.
- lighten, screen: the white spot will remain uneffected from 'healing'.
- patch tool: make rough selection, then either pick 'source' option to drag another spot into the selected spot (it blends it) or pick 'destination' to copy the selection to another spot (its blends too).
- content aware: affects 2 areas. make a rough selection on area A then 'move' it Area B. now area A will have the subject removed and fill autogenerated content in it, and area B will have the subject added to it.
    - play around with structure and color options after using the tool and selection still active to make adjustments.
    - make a selection with lasso or something and then `shift + backspace` to fill selection with content-aware.
