# Basic
- select the tool and choose from these options:
    - shape: makes a vector image.
    - path: makes a path (viewable in path panel), which then can be used to make selection,shape,etc.
    - pixel: exact same as brush tool (just in a particular shape). makes raster.
- path combinations in options when selecting shape tool. (add new, merge, subtract, intersect, exclude).
    - use path selection tool (A) to transform and control individual shapes in a combined shape.
        - during path selection tool, press alt then move over to shape (a plus icon will apear) now when you move the cursor a copy will be created.
    - layer is only 1 in panel but in that each shape has its own combination setting and can be moved independently with A tool.
- you can align multiple shapes in a layer (added by combination option). select all the shapes using A, then chose either align to selection (each other) or canvas.

# Shortucts
- `shift` to keep proportion while tranforming.
    - `space` to move around.
    - `alt` to start from center.

# Custome shape
- make the shape (using Ai, pen tool in photoshop or however)
- make background white and select the shape using shape selection tool.
- right click and 'define custom shape'
