# Access more options
- select shape > properties panel > appearence > stroke (clikc on it)
- cap (for open path), corner (for closed path), align stroke (with binding box), dotted lines, arrowhead, stroke profile.
- instead of using presets from stroke profile you can make you own stroke thickness pattern by width tool `shift + W`.

# Brush on stroke
- you can apply various brush patterns as stroke. go to brush panel or properties > brushes.

# Appearance panel
- allows you to apply multiple strokes and fills and effects on a SINGLE SHAPE.
- each stroke and fill has more options such as opacity and blending mode.
- graphics style panel is presets of different appearence made using above method.
