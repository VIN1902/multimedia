# Shape parts
- bounding box: blue outline for transformation
- center point: for position change
- corner widget: for round corners
- stroke color
- fill color

# Draw a shape
- select tool then click & drag for free form dimensions, later change it via properties panel.
- select tool then click to open dialogue box for width and height.
- press `shift` to keep proportions.
- press `alt` to start drawing from center point.
- press `space` to move while drawing.
- press `up/down` arrow keys to change sides in polygon tool.
- press `ctrl` in case of star shape to change angle b/w arm and body.
- duplicate/transform:
    - select move tool & press `alt` after drawing a shape to then copy and move it around.
    - `ctrl + D` to repeat that previous set of actions.

# Line segment tool
- made up of center point, path and two anchor points.
- `shift` to keep proportions.
- `up/down` arrow keys in case of spiral.
- `up/down` & `left/right` arrow keys in case of grid or polar grid.

# Rounded corners
- normally rounding one corner changes all of them using the widget.
- but if you want to round only one then first click on that one and then drag it using mouse normally.
- First change the roundness of a corner and then go to 'more' transform properties or simply double click the widget then change the corner 'type'.
    - in the same transform panel usually check the scale stroke and effects & scale corners options.

# Eye dropper tool
- selects color, stroke, gradients unlike only color in Ps.

# Arrange
- can do using layer panel
- but right click and arrange
- or use shortcuts after selection `ctrl + ]` send forward 1 step, `ctrl + [` send backward 1 step, use `shift` with them to send at top or bottom.
