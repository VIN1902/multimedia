# Basics
- Ai is used for primarily shapes and texts.
- in tools instead of foreground and background color we have fill and stroke.

# Selection tool
- `V` shortcut.
- click once to select it.
- double click to enter into isolation mode. double click outside anywhere to exit this mode.
- press `shift` and then click multiple objects to keep selecting them. This is achived using ctrl in Ps.

# Properties panel
- when nothing is selected properties of document and artboard is shown.
- the color of artboard (white usually) is NOT a part of main design.

# Layer panel
- In Ai a single layer can have multiple objects in it. (unlike Ps where each object gets seperate layer)
- In a layer we can even have a group of objects or just multiple objects seperately.
- Unlike Ps you can't select object by directly clicking over it on layers panel, you have to either check right most button or use move tool in artboard.
- If you want to use multiple objects as seperate layers in Ae then in Ai those object CAN NOT be within a single layer as group or seperate.

# Navigation shortcuts
- uncheck 'animated zoom' from preferences.
- from any tool press `space` to activate hand tool to move around.
- from any tool use `ctrl + space` then just select area on which to zoom.
- `ctrl + -/+` for zoom out and in.
- `ctrl + 0` to fit in view.

# Using images as reference
- drag and drop the image in Ai
- now normally the image is linked to where its stored on computer (shown by cross inside rectangle in Ai)
- to prevent project file from breaking if the image is deleted from the source, then embedd it into the project.
- do that by going in properties panel.
